# Love PRDXQ Launch ♥
A mobile-friendly web adaptation inspired by [iremcnar/loveYou](https://github.com/iremcnar/loveYou), whose original is a Python desktop animation. This version renders the multilingual heart directly in the browser so it can be visited from a phone.

## Publish
GitHub Actions deploys the static site to GitHub Pages on every push to `main`. In repository Settings → Pages, set the source to **GitHub Actions** if it is not already configured.

The site is public once deployed. Avoid adding private details you do not want visible online.
